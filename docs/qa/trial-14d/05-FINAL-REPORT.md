1. **تكامل خارجي:** واتساب/فيسبوك/Meta Ads (لا حسابات مربوطة).
2. **بوابة ولي الأمر / بوابة المدرس:** لم تُختبر وظيفيًا بعمق.
3. **الدفع الفعلي:** بوابة دفع حقيقية، فواتير، استرداد.

7. **الترقيات/الاستقالات:** المخالصة والتصفية مقروءة فقط (لم تُنفَّذ دورة مالية كاملة).
