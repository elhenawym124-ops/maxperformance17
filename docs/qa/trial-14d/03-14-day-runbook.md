## مخرجات نهاية التجربة (Deliverables)

1. تقرير نتائج 76 سيناريو (`Pass/Fail/Blocked`) + أدلة.
2. قائمة إصلاحات مرتبة بالأثر: حاجز إطلاق → عالي → متوسط.
3. قرار مكتوب: ترقية / تمديد / إيقاف + السبب.
4. لقطات موبايل + سطح مكتب لكل وحدة (للاستخدام التسويقي لاحقاً).

## قواعد ذهبية

- **لا تُعدّل البيانات يدوياً في قاعدة البيانات** أثناء الاختبار — كل الإصلاح عبر المنصة أو السكربت.
- أي بيانات جديدة تُنشأ بأسماء واضحة (`تجربة - …`) لتسهيل الحذف.
- أي فشل تكامل (Meta / واتساب) يُسجّل كـ Blocked وليس Fail.
- التينانت قابل للحذف الكامل في أي لحظة عبر `--cleanup`.
