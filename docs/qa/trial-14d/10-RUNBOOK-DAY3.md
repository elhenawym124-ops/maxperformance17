### تفاصيل الإصلاح
- الواجهة تنادي `GET /hr/leaves/my-history`.
- الكنترولر كان يمرّر `employee.id` (رقم ملف الموظف) إلى `leaveService.getLeaveRequests`.
- الخدمة تتعامل مع `employeeId` **كأنه `User.id`** (تتحقق منه في جدول المستخدمين ثم تفلتر `where.userId`).
- النتيجة: لا تطابق → **قائمة فاضية دائمًا**.
- الحل: تمرير `employee.userId` (مع fallback إلى `req.user.id`).

**التحقق بعد النشر:**
```
GET /hr/leaves/my-history  →  200 · 3 طلبات (منها طلبا اليوم: APPROVED 1ي · REJECTED 2ي)
```
