# Education Management Page

- Path: `/admin/education/*`
- Tabs: dashboard, subjects, packages, groups, students, teachers, enrollments, sessions, calendar, demo-day, flows, funnel, reports, settings, logs
- Payments ledger: `/admin/education/payments` (collections, dues, wallet top-ups, receipts)
- Gated by `education-app` marketplace app
- API base: `/api/v1/education/*`
- Payments API base: `/api/v1/education/finance/*`
- Notification funnel: `/admin/education/funnel`
